Resources

Quick facts that save time

  • Mods load top to bottom: when two change the same file, the one lower in the list wins.
  • Build 42 reads translations as JSON; Build 41 mods often need a Build 42 version (the mod index says which).
  • The game's log is Zomboid/console.txt. The app reads it for you and turns each error into a card.
  • A mod that works alone can still break in multiplayer: the app checks the whole list for it.
Links go to other sites and may change. PZ Mod Studio is a fan-made tool and is not affiliated with The Indie Stone.
