# 模组列表

你已安装的模组：哪些已启用，以及游戏加载它们的顺序。这里的每项更改都会立即保存到当前配置方案和 `Zomboid/mods/default.txt`（游戏读取的列表）中。

## 你会看到什么

- 标题栏统计创意工坊项目、模组、**已启用**的模组，以及地图、库和脚本模组的数量。出现问题时会显示红色和琥珀色的计数器（**缺少前置**、**前置已禁用**、**不兼容**、**列表顺序**）；点击一个可以逐个跳到这些模组。
- 工具栏：搜索、筛选、分组，以及**全部启用** / **全部禁用**按钮。
- 列表。顶部的绿色横条（**最先加载**）是放库模组的地方；底部的琥珀色横条（**最后加载**）是在两个模组共有的文件上胜出的位置。
- 右侧是你选中的模组的面板（点击一个之前是空的）。详见下方的**右侧面板**。

## 右侧面板

顶部始终可见：模组的图片（点击查看原图）、它是地图、库还是脚本模组、它的来源（Steam、兼容副本、本地……）、它的名称、ID、作者和版本，以及**支持作者**按钮，带有作者在更新日志或创意工坊中放的链接（Ko-fi、Patreon……），在你的浏览器中打开。下面是一个启用或禁用它的按钮（并说明它在哪里加载），以及**在浏览模组中查看**。

然后是三个标签页（切换模组时保持你选的那个）：

- **Studio**：本应用对你列表中这个模组所了解的内容。
  - **备注**：你的完整备注（**编辑备注**或**添加备注**）、你的分组以及它所在的配置方案，当前的那个会高亮。
  - **要做什么**：检查发现的每条警告及其完整内容，说明你需要处理、值得处理还是仅供了解，以及它的修复按钮。没什么要做时，会用绿色说明。
  - **上次游戏**：游戏记录的错误或警告（附最后一行）、它加载用了多久，以及它占游戏时间的比例。
  - **依赖**：它需要什么，以及哪些模组需要它；点击一个可以跳到它所在的行。
  - **模组元数据详情**（它的 `mod.info` 写了什么，附**更新日志中的最新内容**）和**它的 Java 修改的类**，折叠在最后。
  - **要做什么**和**上次游戏**点击标题即可折叠，并保持你离开时的状态。
- **创意工坊页面**：不离开本应用就能看模组的页面：图片和视频、订阅数、收藏数、大小、日期、作者、类别、它需要的项目（你有的为绿色：点击跳到它的行；没有的为琥珀色：在浏览模组中打开）以及带**翻译**的完整简介。不在创意工坊上的模组会在这里显示它自己的描述。
- **评论**：它创意工坊页面上的评论，最新的在前，带有**加载更多**。作者的个人资料为私密时，Steam 不显示评论，面板会说明这一点。

## # 列

每行的数字是该模组在**已启用**模组中的位置：即游戏读取的加载顺序，也是游戏显示的同一个数字。已禁用的模组显示 **—** 并变灰，因为它在加载顺序中没有位置。已禁用的模组保留它在列表中的位置，所以重新启用时它通常会回到原来的地方。

## 启用和禁用模组

- 点击行上的方框，或右键点击并选择**启用** / **禁用**。
- 当一个模组需要其他模组时，会弹出一个窗口，列出会随它一起启用（以及随它一起禁用）的模组。选择**全部启用 N 个**，或**只启用 ...**只处理这一个模组。
- **全部启用**和**全部禁用**只作用于当前显示的行（经过搜索和筛选后），并会先询问。
- **撤销** / **重做**（它们旁边的箭头，或 Ctrl+Z / Ctrl+Y）在这里做过的更改中后退和前进：移动、拖动、启用禁用、排序。每个配置方案都有自己的记录，关闭本应用后也会保留。
- Ctrl+点击选择多个模组，Shift+点击选择一段范围，Esc 取消选择。在选中的模组上右键点击：启用或禁用它们、把它们移出配置方案，或取消订阅它们的创意工坊项目。
- 模组合并器中处于打开状态的草稿补丁包，在打包之前无法启用。

## 调整加载顺序

- 按住行号拖动一行，放到另一行的上方或下方。中间隐藏的行会被考虑在内。
- 右侧的箭头按钮：移到最上、上移一位、下移一位、移到最下。上移和下移会与完整列表中相邻的模组交换，那可能是一个已禁用的模组。
- **位置 #**：输入一个数字，然后点击**前往**或按 Enter。该模组会移到已启用模组中的那个位置。
- **自动排序依赖**：把每个模组放在它需要的模组和它的 `loadModAfter` 模组之后、它的 `loadModBefore` 模组之前，并排在你自己的规则所指定的模组之后。其余一切保持你的顺序；PZ Mod Studio 的补丁包放在最后。一个窗口会说明移动了多少个模组，并提供**撤销**。

## 查找模组

- 搜索框匹配名称、模组 ID、创意工坊 ID 和你的备注。
- 筛选按钮：**全部**、**已启用**、**已禁用**、**收藏**、**已更新**、**有问题**、**地图**、**库模组**、**无法加载**。每个都显示数量。
- 下面是：**排序：加载顺序**、**排序：名称**、**排序：最新安装**或**排序：最早安装**（按每个模组的安装时间：它的文件夹创建的时间；创意工坊模组按首次下载时间，更新不会改变它；每行显示日期，未安装的模组排在最后）、**分组**菜单、你的某个分组、来源（**Steam 创意工坊**、**你上传的创意工坊项目**、**手动安装**、**兼容副本**……）、一个标签（上次游戏有错误或警告、加载慢、对游戏负担重、诊断发现的问题），以及**配置方案的模组** / **所有已安装**。
- 游戏的模组界面（Studio Link 模组）有同样的筛选，顺序也相同。已更新、库模组、分组、来源和标签需要 PZ Mod Studio；没有它时，游戏会在这些位置说明。
- 按名称排序时也可以拖动：模组会移到你放下时所在的那个模组的位置。
- **清除筛选**会重新显示所有模组。

## 分组和备注

- **分组**菜单把列表排成可折叠的分区：**分组：无**、**分组：作者**、**分组：类别**或**分组：我的**。每个标题显示已启用的数量，并有**全部启用** / **全部禁用**。在**分组：我的**中，备注按钮可以编辑分组的备注。
- 右键点击模组并选择**分组…**，可以勾选它所在的分组、新建一个（**加入其中**）、重命名或删除分组。变空的分组会消失。分组从不改变加载顺序。
- 选择你的某个分组时会显示**启用此分组**（连同其模组需要的模组）和**禁用此分组**。
- 右键点击并选择**添加备注…**可以给模组写备注（右侧面板也可以）。它的行会在名称旁显示备注的开头：悬停可以阅读全文，点击可以编辑。
- 每个配置方案都有自己的分组：分组属于你创建它时所在的配置方案。备注是针对模组的，在每个配置方案中都一样。
- 备注和分组只属于你。游戏会在 Studio Link 模组的模组界面中显示它们（当前配置方案的分组）。

## 配置方案的模组

有当前配置方案时，列表显示该配置方案的模组。**配置方案的模组**按钮可以切换到**所有已安装**，列出所有已安装的模组，并为每个标出它所在的配置方案。不在任何配置方案中的已安装模组（例如从 Steam 网站订阅的）会出现一条蓝色横条，带有**加入配置方案**（加入时为禁用状态）、**显示它们**，或用 X 隐藏横条。

## 右键菜单

**启用/禁用**、**加入配置方案** / **移出配置方案**（移出也会禁用它）、**移到最上**、**移到最下**、**在浏览模组中打开**（对未安装的模组为**在浏览模组中搜索它**）、**打开它的文件夹**、**添加备注…**（有备注后为**编辑备注…**）、**分组…**、**加载顺序规则…**、**保留此版本**、**版本…**、**收藏**、**加入列表…**、**加入配置方案…**、**复制模组 ID** 和**取消订阅它的创意工坊项目**（Steam 会删除它的文件；同一项目中的其他模组也会一起消失）。

- **加载顺序规则…**：规定某个模组必须在另一个之后加载（你在游玩中发现的情况）。自动排序会遵循规则，列表违反规则时诊断会发出警告。要把你的顺序分享给别人，请导出一个预设：它带有按你的规则排好顺序的列表。
## 回到旧版本

Steam 不会保留创意工坊模组的旧版本：更新会替换它的文件，也没有办法下载之前的版本。所以 Studio 会自动在 Steam 替换之前，把配置方案使用的每个创意工坊模组的已安装版本复制一份。当某次更新弄坏了东西时，之前的版本已经在这台电脑上了。

- **版本…**（右键菜单；简洁视图中也有）列出该模组保留的各个版本：每个版本何时保留、它的 modversion、作者何时发布，以及标签：**当前已安装**（与 Steam 的文件相同）、**使用中**、**由 Studio 保留**或**由你保留**。
- **使用此版本**会把它作为本地副本放进 `Zomboid/mods`，游戏会读取它而不是创意工坊的版本（从 Studio 启动时）。创意工坊文件夹不会被动到，所以 Steam 不会把它改回去。游戏运行时会拒绝。
- **回到创意工坊版本**（在同一个窗口中，或诊断中的修复，该模组会显示**正在使用保留的版本**）会把副本移到备份中；游戏会重新读取创意工坊的版本。
- 当保留了旧版本或正在使用某个旧版本时，模组的面板会说明，并提供**版本…**按钮。
- **保留此版本**（完整视图）会手动保留模组今天的样子：大小上限永远不会删除它。

副本存放在 `Zomboid/PZModStudio_Versions` 中，或设置 > 本应用中选择的文件夹（**选择文件夹…**，例如另一个磁盘）。每个文件只保存一次，所以更新后的一个版本只占用更新改动的部分。上限（默认 10 GB；磁盘总会保留其容量 15% 的空闲）和开关在设置 > 本应用中；超过上限时，最旧的旧版本先被删除，然后是不在当前配置方案中的模组副本。以前制作的副本（`Zomboid/PZModStudio_Snapshots`）仍会列出。

## 行标签

每行只显示需要你处理的内容，让列表保持易读：

- 需要你处理或值得处理的诊断警告（例如**需要一个已禁用的模组**或**加载得太早**），旁边有应用修复的扳手按钮。点击标签可以跳到相关模组或诊断。
- 仅供了解的内容会收进一个带 **i** 和数量的小标签；右侧面板会全部显示。
- 上次游戏中游戏为该模组记录的错误或警告、超过 1 秒的加载时间，以及从 5 % 起它占游戏时间的比例（在“诊断 > 模组 > 每个模组的耗时”中测量）。
- 它的来源，仅在不是 Steam 时显示（**本地**、**兼容副本**……）。
- 在**所有已安装**中，会有一个带数字的配置方案图标：在当前配置方案中时显示 **✓**（也在其他配置方案中时加 **+N**），否则显示有多少个配置方案包含它。悬停可以看到它们的名字。

较短的加载时间、Steam 来源和其他一切都在右侧面板中。

## 以前的列表和预设

- **以前的列表**是列表的撤销功能。Studio 每次写入列表时，都会保留之前的那个。选择一个并点击**回到这个列表**；你当前的列表也会被保留。
- **预设**按钮可以把列表保存为一个有名字的预设、载入一个预设，或导出和导入 `.pzpack` 文件。导入的包会列出你缺少的模组，并提供**全部订阅**。

## 小提示

- 订阅或取消订阅后，**刷新**会重新扫描模组文件夹。
- PZ Mod Studio Link 模组在每个配置方案中都保持启用，有当前配置方案时它会从列表中隐藏。
- 游戏运行时，这里做的更改会在主菜单（通过 Studio Link 模组）传到游戏，或通过其模组界面上的**与 PZ Mod Studio 同步**传到游戏。
