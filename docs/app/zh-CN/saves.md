# 存档

你的 Project Zomboid 存档及其备份。Studio 会在存档最容易出事的时候自动备份；在这里你可以查看这些备份、自己做一个备份、永久保留某个备份，或者恢复一个备份。

## 每个配置方案的存档

每个配置方案都有自己的存档。存档属于你上次在 Studio 打开的情况下游玩它时的当前配置方案；没有 Studio 时游玩的存档，只有当某个配置方案的模组与存档的完全一致时才属于该配置方案。存档永远不会被移到另一个配置方案。

- 这个界面显示当前配置方案的存档。**显示全部（另有 N 个）**会加上其他配置方案的存档和不属于任何配置方案的存档，每个都带有**配置方案：<name>**或**无配置方案**的小标签。**仅 <name> 的存档**回到当前配置方案的存档。
- 服务器的存档显示为它的地址（`ip:port`），带有**在线**小标签，属于你从**服务器**界面加入该服务器时使用的配置方案（Link 不在服务器上运行，所以 Studio 依据它自己的服务器列表）。
- 在游戏中，有 Studio Link 模组时：**载入游戏**界面列出当前配置方案的存档，搜索框旁边有**显示全部**；**继续游戏**会载入当前配置方案最新的存档（配置方案没有存档时它会被隐藏）。没有 Studio 时，游戏照常列出所有存档。

## 你会看到什么

- 顶部的**打开备份文件夹**会打开备份所在的文件夹（`Zomboid/PZModStudio_SaveBackups`），圆形箭头刷新界面。
- 一条显示磁盘空间的横条：剩余多少、磁盘大小，以及备份占用了多少。当你最大的存档可能放不下两次时，它会变成琥珀色并显示**空间不多了**。
- 每个存档一行：世界名称，然后是游戏模式、大小、文件数、模组数和最后修改时间。**制作于 <build>** 小标签写明写入该存档的游戏版本；更新的游戏版本会在你载入时升级它。
- 如果存档的模组自上次游玩以来有变化，会有一行琥珀色文字说明：**自上次游玩以来（...）**，写明新增、移除、更新了多少个模组，或顺序有变化。把指针停在上面可以看到模组名称。
- 如果存档的模组列表中有未安装的模组，会有一行红色文字说明：**无法载入：它的列表中有 N 个模组未安装**，每个模组一个按钮。点击一个可在**浏览模组**中打开它（列表写明了创意工坊项目时打开该项目，否则搜索它的 ID）。服务器的存档没有自己的列表：加入时游戏会下载服务器的模组。
- 如果存档自己的模组带有存档没有载入的地图，会有一行琥珀色文字说明：**没有载入它的模组中的 N 张地图**，每个地图文件夹一个小标签。存档会保存它创建时的地图列表，游戏从不往里添加，所以之后启用的地图模组载入时没有它的地图（它的地图格位置是一片空地）。在游戏关闭时，**把地图加入存档**会在确认后备份存档、把这些地图加入它的列表，并把这些地图格中已经生成的空地移到备份文件夹。
- 当活动配置方案中启用了存档自身列表里没有的模组时，会有一行绿色提示：**<配置方案> 中启用的 N 个模组不在此存档中**，每个模组一个标签（地球图标表示带有地图区域）。存档按自己的列表载入，而不是按配置方案，所以存档创建后才启用的模组不会随它载入。在游戏关闭时，**加入此存档** 会先备份存档，确认后按配置方案的载入顺序把它们放进存档的列表；它们带来的地图会像 **把地图加入存档** 那样加入。其他配置方案的存档不会被改动。
- **角色和车辆**会打开存档中的内容，从存档自己的文件读取：每个角色的名字、位置、是否死亡和携带的物品，以及每辆车的位置、离角色多远和里面有多少物品。物品数量是近似值。
- 每行右侧显示它的状态：
  - **已按现状备份**：最新的备份与存档一致。
  - **自 ... 的备份以来有变化**：存档在最后一次备份之后发生了变化。
  - **没有备份**：还没有备份。
  - 备份进行时显示**正在备份...**。

## Studio 什么时候备份

- **你离开时**：当你回到主菜单，或你在存档中时游戏关闭。
- **以变化的模组载入之前**：当你载入的存档的模组与上次游玩时不同，或自那以后有更新时，Studio Link 模组会请求备份。
- **修改其模组列表之前**：当存档的模组列表即将在游戏中被修改时，或在**把地图加入存档**之前。
- **恢复之前**：在你恢复一个较旧的备份之前，先保存存档当时的样子。

自最新备份以来没有变化的存档不会再次压缩。

## 自己做备份

点击该行的**立即备份**。备份是一个 zip 文件，写入后会读回校验；校验过的备份显示**已校验**。如果存档没有变化，就不会生成新的 zip：而是把最新的备份标为保留。当磁盘空间不足以放下存档外加一些余量时，按钮会变灰。

## 一个存档的备份

点击某行左侧的箭头打开它的备份。每个备份显示制作时间、原因（**由你制作**、**你离开时**……）、zip 大小、存档大小、文件数和模组数。每个备份可以：

- 图钉用来保留它：保留的备份永远不会为腾出空间而被删除。再点一次让它重新变成自动备份。
- **恢复**会在确认后把该备份放回作为存档。
- 垃圾桶按钮（**删除此备份**）会在确认后删除它。此操作无法撤销。

## 恢复存档

1. 关闭 Project Zomboid。游戏运行时会拒绝恢复。
2. 打开存档的备份，在你想要的那个上点击**恢复**。
3. 确认。Studio 会校验备份，把存档现在的样子备份一份（这样你可以撤销），把备份解压到存档旁边，最后才交换两者。

## 小提示

- 每个存档保留最新的 5 个自动备份；生成新备份时，较旧的会被删除。你自己做的或钉住的备份会一直保留，直到你删除它们。
- 自动备份需要你游玩时 PZ Mod Studio 处于打开状态，并且游戏中启用了 Studio Link 模组（它会在你进入和离开存档时通知本应用）。
- 服务器的存档在 Studio 打开的情况下游戏关闭时备份，前提是它在那次游戏中有变化。
- 本应用关闭时，Link 模组会在载入前提醒存档无法备份，并允许你不备份继续。
- Link 模组还可以在副本（`<world>_copy`）上游玩存档，副本由本应用制作；原存档保持不变。
- 在游戏中载入存档时，Studio Link 会先问同样的问题：**添加并载入**（应用先备份存档再添加）、**不添加直接载入**（存档保持原样）或 **返回**。添加需要打开 PZ Mod Studio。
