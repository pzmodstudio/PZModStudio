# PZ Mod Studio

PZ Mod Studio 是一款免费的 Windows 版 Project Zomboid 模组管理器。它把你的模组整理成配置方案，备份你的存档，按游戏读取的方式检查你的模组列表，并帮你修复出问题的地方。在任何界面按“?”都能打开该界面自己的帮助页。

第一次打开 Studio 时会显示**欢迎导览**：右下角的一张卡片带你逐一了解每个界面，背后显示的是真实界面，侧边栏中对应的按钮会亮起，同时还会告诉你 Studio 已经了解到的安装情况（找到的文件夹、你的配置方案、列表中的问题）。用**下一步**或方向键继续；点 X 关闭。想再看一次，打开帮助（“?”）并点击**再次显示欢迎导览**。

## 各个界面

侧边栏在 **Studio 模块**下列出所有界面。带锁的界面需要先有一个当前配置方案：在“配置方案”中创建或激活一个。

- **配置方案**：有名字的模组列表；创建它们，一键切换，并以 `.pzpack` 文件分享。
- **存档**：你的存档及其备份；创建、保留或恢复备份。
- **监控中心**：启动游戏并阅读它的日志，每个错误一张卡片，并注明来自哪个模组。
- **模组列表**：启用和禁用模组、设置加载顺序，支持筛选、分组、备注和撤销。
- **最近更新**：自你上次游玩以来更新过的创意工坊模组，附带更新说明，并在更新可能损坏存档时提醒你。
- **诊断**：本应用对你的模组所了解的一切（按游戏读取的方式检查：缺少或已禁用的前置模组、错误的顺序、不兼容的模组、你的游戏版本无法加载的模组，并给出修复办法）、游戏本身（内存、CPU、启动、帧、磁盘）以及在你电脑上运行的服务器；首页有医生。
- **浏览模组**：搜索 Steam 创意工坊、订阅、维护你自己的列表，以及安装从别处下载的模组。
- **地图**：在游戏世界上显示每个地图模组占用的地图格，以及两个地图模组争夺同一批地图格的地方。
- **模组合并器**：当两个模组修改同一个文件时，把它们合并成一个最后加载的补丁包。
- **开发者**：面向模组作者：在游戏之前检查模组的 Lua 和脚本文件，并只启用该模组来启动游戏。只有在应用设置中打开**开发者功能**后才会显示。
- **服务器**：建立和管理专用服务器，并让它的模组与你的保持一致。
- **应用设置**：你的游戏和模组在哪里、显示哪些警告，以及其他选项。

## 启动游戏

右上角的绿色按钮会用你的模组列表启动 Project Zomboid。旁边的箭头打开菜单：

- **启动方式**：带调试（`-debug`，监控中心实时跟踪日志）或普通游戏，每种都可以全屏或窗口。
- **去哪里**：**主菜单**（和平常一样），或**自定义…**，它会打开**自定义启动**，直接前往某个地方：
  - **存档**：你的单人存档，当前配置方案的排在前面。游戏打开后，在主菜单由 Studio Link 模组载入该存档，提示和备份与**继续游戏**相同。之后是游戏黑色的“点击开始”画面。
  - **服务器**：你保存的服务器。加入方式与“服务器”界面中的**加入**相同，使用保存的密码和你的用户名；游戏会载入服务器的模组。
  - **方式**选择启动方式。**选定**把它设为按钮的目的地；**选定并启动**还会同时启动游戏。**回到主菜单**清除它。

选定目的地后，按钮会显示它的名字（**游玩：（存档）**或**加入：（服务器）**），并且在设置中打开**记住游戏的启动方式**时，会像启动方式一样被记住。

## 游戏中的 Studio Link 模组

PZ Mod Studio Link（`Z_StudioLink`）是一个适用于 Build 42 的小模组，由 Studio 安装，并在每个配置方案中保持启用。它是本应用在游戏里的一端。其中一部分可以单独工作，其余部分需要本应用。

### 它自己的模组界面

主菜单的**模组**按钮会打开 Link 的模组界面，而不是游戏原来的界面。单独使用时它提供：

- 所有已安装的模组，带搜索框（名称、模组 ID、创意工坊 ID、作者）和筛选（**全部**、**已启用**、**已禁用**、**收藏**、**已更新**、**有问题**、**地图**）；
- 每个模组的详情：它需要什么、什么需要它、适用的游戏版本、它的创意工坊页面；
- 连同前置模组一起启用或禁用模组，用 Ctrl 或 Shift 可一次处理多个；
- 加载顺序：按它排序、上移下移或拖动，永远不会高于模组所需要的模组；
- 按作者或类别分组、每个模组的选项（**模组选项**）、**地图顺序**，以及**撤销** / **重做**；
- **共享文件**：当两个已启用的模组带有同一个 Lua 文件时，游戏只运行其中一份，即加载顺序靠后的那个模组的。使用了自己那份的模组标为**覆盖**，没被使用的标为**被覆盖**；汇总按钮 **N 个共享文件**会列出它们（它的提示解释了这些标记），每个模组的详情会写明文件和另一个模组。检查对象是游戏实际加载的模组，在主菜单出现几秒后进行；只检查 Lua 文件；
- **重新加载模组**让游戏重新读取模组文件夹，这样游戏运行时订阅（或更新）的创意工坊项目无需重启就会出现；游戏会重新加载它的 Lua，和**应用**之后一样；
- **服务器配置行**把已启用的模组复制成专用服务器的 `Mods=`、`WorkshopItems=` 和 `Map=` 行，按加载顺序排列（每个模组排在它需要的模组之后，地图按地图顺序），用来粘贴覆盖 `Zomboid/Server` 中服务器 `.ini` 的那几行；没有创意工坊项目的模组会写在一行注释里，需要复制到服务器自己的模组文件夹；
- **应用**保存到游戏读取的列表中，和游戏自己的界面一样。**游戏原界面**打开原来的界面。

有本应用时，同一个界面还能只显示配置方案的模组（**配置方案的模组** / **所有已安装**），显示诊断对每个模组的警告、自你上次游玩以来更新过的模组（在详情中显示作者最新的更新说明，以及更新是否可能损坏存档）、你的备注和分组，以及一个把不在任何配置方案中的新模组加进来的按钮。**与 PZ Mod Studio 同步**会接收本应用所做的更改，**打开 PZ Mod Studio** 会把本应用调到前台。

如果启用了另一个接管模组界面的模组管理器，Link 会问你想用哪个界面，如果你这样选择，就把界面交给另一个。

### 主菜单上的卡片

当本应用在这台电脑上运行过时，主菜单上会有一张卡片，显示本应用是打开还是关闭、当前配置方案及其模组数量、诊断的错误和警告，以及**继续游戏：（存档）**和自上次游玩以来它的模组有什么变化。如果从未安装过本应用，卡片会改为邀请你获取它，带有**下载**（复制下载页面的地址）和**隐藏**。

### 错误提示

当游戏记录到一个 Lua 错误时，会弹出提示，写明它来自哪个模组（以及是哪个模组调用的），并显示最后一条消息。**复制报告**把错误放到剪贴板，方便发给模组作者；**在模组中显示**在模组界面打开该模组；**在 Studio 中查看**在监控中心打开它的卡片。如果已启用另一个会显示这些错误的模组，这个提示就不会出现。**全部（N）**以及暂停菜单上的 **Lua 错误（N）**会打开本次游戏的所有错误，每种只列一次并注明出现次数、所属模组和文件:行号：点击可复制一个，**全部复制**会连同游戏版本、模式和已启用的模组数量一起全部复制。报告中每个模组都写明它的 ID、版本和创意工坊项目。

每个错误在发生后一秒内也会写入 `Zomboid/Lua/PZModStudio_LinkErrorLog.txt`，所以崩溃、断线或回到菜单都不会丢失：每种错误完整记录一次（模组、文件:行号、消息、堆栈），重复的只计数；每段开头有日期、游戏版本，以及当时是在菜单还是哪个存档；游戏回到主菜单或服务器断开连接的地方也有一行记录。该文件大约保留最近 3000 行。列表中的**错误日志**会打开它所在的文件夹并复制它的路径。

给模组作者：`PZModStudioLink.registerReport("YourModId", fn)`（或者在比 Link 更早运行的 Lua 中使用 `PZModStudioLinkReports["YourModId"] = fn`）可以把你自己的信息加进报告。`fn(err)` 返回一个字符串、一个行列表或一个 名称 = 值 的表；它只在生成报告时运行，并且在 `pcall` 内运行。它的文本会出现在**全部复制**中，对于你的模组的错误，还会出现在**复制报告**和错误日志中。其他模组的调试报告（即模组已经为错误工具注册的那些）也会以各模组给出的名称放进同样的地方。

右下角游戏自己的红色 **ERROR** 计数器是由游戏的 Java 绘制的，Lua 无法触及：Link 无法隐藏它。

### 加入服务器

当游戏因为某个创意工坊模组与服务器的不一致而断开连接时，Link 会写明是哪个模组（游戏只给出一个数字），说明这种情况该怎么办（服务器重启后会更新，或者需要 Steam 下载新版本），并提供**复制创意工坊链接**。当游戏版本与服务器的不同时，它会说明这一点并给出两边的版本。

建立服务器时（**建立服务器**、**启动**），游戏载入的是该服务器配置自己的模组列表，而不是模组界面的。如果那个列表缺少你已启用的模组，或者列出了这台电脑上没有的模组，Link 会先询问：**是**仍然建立服务器，**否**返回（**编辑配置文件**可以修改它的模组）。

### 两个模组都修改的函数

当诊断发现两个模组重新定义了同一个函数时，Link 会在主菜单出现几秒后以及存档载入后询问游戏：最终保留下来的那个函数来自哪个文件。诊断会把它显示为**在运行中的游戏里看到**。

### 有无本应用的区别

- 没有本应用：Link 的模组界面（含**服务器配置行**）、错误提示及其错误日志（没有**在 Studio 中查看**），以及邀请卡片。
- 有当前配置方案时，即使本应用已关闭：模组界面显示本应用上次留下的配置方案；在载入画面中，每个存档都会标出它的模组是否与配置方案相符；使用配置方案之外模组的存档无法载入；模组列表为空的存档会先询问。
- 只有本应用打开时：模组发生变化的存档在载入前以及你离开时的备份、在副本上游玩存档、把新模组加入配置方案、**同步**、**打开 PZ Mod Studio** 和**在 Studio 中查看**。
- 备注、分组、配置方案和诊断都是在本应用中制作的；游戏只负责显示。
