# 应用设置

在“应用设置”中，你告诉 Studio 你的游戏和模组在哪里，并选择 Studio 的行为方式：语言、窗口、警告、启动方式，以及一些可选的附加功能。每项更改在你做出的那一刻就会保存。

## 简洁与完整

顶部的卡片**要显示多少 Studio 内容**用来在两种视图之间选择。同一个开关始终在左侧栏底部的**视图**下。切换它永远不会删除或禁用任何东西：它只是显示或隐藏界面，你随时可以来回切换。

- **简洁**显示玩模组所需要的内容：
  - **首页**：正在使用的配置方案、**开始游戏**、**继续游戏**（用这个配置方案玩的上一局，有了之后才会显示），以及一行体检结果：没什么要做时为绿色，有需要先修复的问题时为红色并显示**查看要做什么**。
  - **配置方案**、**模组列表**、**浏览模组**、**存档**和**诊断**。
  - **模组列表**让你启用和禁用模组、排序（手动或用**自动排序**）、搜索，并按已启用、已禁用和有问题来筛选。只有需要修复的地方才会用红色和浅白的话标出，旁边有对应的按钮。分组、备注、预设、其他筛选和加载耗时都留在完整视图中。
  - **诊断**会直接打开你需要处理的问题，每个都有一个按钮。可选的建议（没有它们游戏也能运行）以及仅供了解或已经修复的内容，只在列表下方计数而不显示；**显示全部（完整）**会显示它们。**自动修复 N 个问题**只统计并修复你看到的列表中的行：隐藏的建议不会被动到。
  - 这里的设置保留**目录路径**、**提醒**和**本应用**标签页。
- **完整**是整个 Studio：侧边栏中的每个界面（监控中心、最近更新、地图、模组合并器、服务器、开发者）、诊断的每个标签页以及设置的每个标签页。

新安装从**简洁**开始，带有三步欢迎：在哪里找到了你的游戏、创建或选择一个配置方案、开始游戏。如果这台电脑上已经用过 Studio，它会从**完整**开始，和以前一样，并且第一次时顶部会有一行邀请你试试简洁视图：**试试简洁**或**不用了，谢谢**。它只显示一次，如果你已经选过视图就不会显示。这个选择会记在这台电脑上。

其他界面中的链接仍然可以打开简洁视图隐藏的界面（例如医生给出的步骤）；它打开期间会显示在侧边栏中。

## 你会看到什么

界面顶部并排有几个标签页：

- **目录路径**：游戏、创意工坊、你的 Zomboid 文件夹和模组列表在哪里。
- **提醒**：Studio 向你显示哪些警告。
- **本应用**：Studio 的启动方式、窗口和关闭按钮、语言、是否记住游戏的启动方式、游戏的模组界面、检查新版本以及翻译。
- **高级**：本应用的诊断信息、开发者功能，以及（开启开发者功能时）你在 ZombieBuddy 中允许的 Java 模组。
- **Build 42 修复**：Build 42 兼容层涵盖的内容，它修补的每个模组都有一个开关。
- **MCP 代理服务器**：只在开启**开发者功能**时显示。

## 文件夹

点击**自动检测路径**，让 Studio 自己找到一切。要手动设置某个文件夹，点击它旁边的**浏览...**。一条**已保存。**的提示会确认更改。

- **Project Zomboid 安装目录**：包含 `ProjectZomboid64.exe` 的文件夹。文件夹正确时显示**找到了游戏**，不正确时显示 **Studio 在这里找不到游戏**。Steam、GOG 和手动安装都可以。
- **Steam 创意工坊文件夹（不使用 Steam 时可不填）**：Steam 下载创意工坊模组的位置（`workshop/content/108600`）。如果你在 GOG 上玩，或者手动把模组放进 `Zomboid/mods`，就留空。
- **用户 Zomboid 目录（数据和本地模组文件夹）**：你的 `C:\Users\<User>\Zomboid` 文件夹，包含日志、存档、配置方案和本地模组。必填。
- **模组列表文件（Zomboid/mods/default.txt）**：游戏通过它知道哪些模组已启用以及顺序。它会被自动找到；这里的**浏览...**选择的是文件，不是文件夹。

没有有效的游戏文件夹时，模组合并器等界面会请你先来这里设置。

## 警告

在**系统通知和警告**下，你可以关闭或恢复三条消息：

- **启动时关于未合并模组冲突的警告**：当你已启用的模组共享了文件、而没有任何已启用的合并补丁包合并它们（或合并的是模组的旧版本）时，启动前显示的警告。
- **启动时关于定义相同内容的模组的提示**：当两个已启用的模组以不同方式定义了同一个物品、配方或文本、且没有补丁包决定保留哪个时，启动前显示的提示。不会坏掉什么：最后加载的那个胜出。
- **自动排序依赖的说明消息**：在模组列表中对依赖排序时显示的说明。

每条都有**关闭警告** / **恢复警告**（或**关闭通知** / **恢复通知**）。

## Studio 的启动方式和窗口

- **Studio 启动时应该打开什么？**：**配置方案界面（开始）**（推荐）显示配置方案管理器；**直接打开上一个配置方案**会载入上一个当前配置方案并打开模组列表。
- **按我离开时的样子打开窗口**：同样的大小、位置和显示器，之前是最大化或全屏的也照旧。如果那个显示器已经不在了，就在主显示器上打开。
- **关闭按钮（X）**：**关闭 Studio** 会退出它（游戏如果开着会继续运行）。**保留在系统托盘中，时钟旁边**会隐藏窗口，Studio 继续关注游戏（退出时的备份、游戏模组界面中的配置方案）。点击托盘图标可再次打开它；它的菜单中有**退出**。

## 语言

在**语言**下选择应用的语言：English、Español、Português (Brasil)、Français、Deutsch、Русский 或 简体中文。某种语言中缺少的文字会以英文显示。游戏自己的消息（错误、警告、监控中心的日志行）保持游戏写入时的样子。

## 游戏启动方式和游戏的模组界面

- **记住游戏的启动方式**：开启时，启动按钮会使用你上次用的方式（调试、窗口、普通……）。关闭时，它总是以推荐的调试模式（全屏）启动。
- **游戏的模组界面（启用了另一个模组管理器时）**：只有一个模组管理器能绘制游戏的模组界面。当另一个启用时，选择**在游戏中问我**、**PZ Mod Studio 的（另一个被启用时会再问）**或**另一个管理器的**。无论哪种，存档备份和存档载入前的检查都仍由 PZ Mod Studio 负责。

## 应用更新

- **检查 PZ Mod Studio 的新版本**：在启动时以及打开期间每 6 小时，Studio 会向 GitHub 询问最新的发布版本。有更新的版本时，标题栏下方会有一条横幅提示。**立即更新**会下载新版本，检查它是否由本项目签名（`SHA256SUMS.txt` 的签名和 zip 的 SHA-256），把它放到你的版本的位置并重启 Studio；如果有任何不符，什么都不会改变。**下载**会在你的浏览器中打开发布页面，**以后再说**会隐藏提示，直到下一个版本。当 Studio 安装在它无法写入的文件夹中时（Program Files，供所有用户使用），请用页面上的安装程序更新。除非你要求，否则什么都不会安装，也不会发送任何内容。**立即检查**会马上询问。GitHub 没有回应时，Studio 会改为询问它的 itch.io 页面；这时提示只提供下载页面，不提供**立即更新**。关闭时，不会询问 GitHub。

## 模组的旧版本

- **保留模组的旧版本**（默认开启）：Steam 不会保留创意工坊模组的旧版本。Studio 会在 Steam 替换之前，把配置方案使用的每个创意工坊模组的已安装版本复制一份到 `Zomboid/PZModStudio_Versions`；模组列表中的**版本…**可以把某个版本放回去。**最多**设置它可以占用的空间（默认 10 GB；你自己选的上限会保持不变）；每个文件只保存一次，所以更新后的一个版本只占用有变化的部分。超过上限时，最旧的旧版本先被删除，然后是不在当前配置方案中的模组副本；手动保留的版本会留下。无论上限是多少，Studio 都不会塞满磁盘：每轮总会保留磁盘容量的 15% 空闲，当这一点成为限制时，卡片会显示**受 D: 剩余空间限制**（并显示目前适用的上限）。**文件夹**显示副本在哪里以及占用多少；**选择文件夹…**会移动它们，例如移到另一个磁盘：每个文件都会被复制并与原文件比对，之后才删除旧文件夹（在同一个磁盘上只是重命名）。已经有其他文件的文件夹会在其中建一个 `PZModStudio_Versions` 文件夹。游戏运行时或某一轮正在进行时，以及对于磁盘根目录、Steam 的创意工坊文件夹、游戏文件夹、`Zomboid/mods` 和 `Zomboid/Saves`，都会拒绝移动。下面一行显示已用多少空间以及你的创意工坊模组有多少已被覆盖；因空间不足而没有副本的模组会被列出。**立即保留**会马上运行一轮（Studio 启动后不久以及 Steam 更新任何内容时，它也会自动运行）。游戏运行时不做任何操作，创意工坊文件夹只会被读取。

## 诊断信息

**诊断信息**会收集错误报告需要的内容：Studio 和 Windows 的版本、各个文件夹、游戏版本、当前配置方案、Studio Link、Zombie Buddy、Steam 是否在限制请求，以及 Studio 日志的末尾。**复制诊断信息**会复制它；你的 Windows 用户名和电脑名会被替换为 `<user>` 和 `<pc>`。粘贴到任何地方之前请先看一看。**打开日志文件夹**会打开 Studio 自己的日志所在的文件夹。

## 翻译

浏览模组在模组页面上有一个翻译按钮，还有一个用来翻译一页结果的简介；开发者界面的翻译草稿也使用同一个服务。没有密钥时，使用免费的 Google 翻译服务（它是非官方的，某天可能会停止）。有 DeepL API 密钥时（每月 500,000 个字符以内免费），会优先使用 DeepL：点击**获取 DeepL 密钥**，粘贴后点击**检查并保存**。密钥只保存在这台电脑的 Windows 凭据管理器中；**移除**会删除它。已经翻译过的内容会保存在这台电脑上，所以同一段文字不会再次发送；**删除它们**会清除这些翻译。

## 开发者功能

**开发者功能**会在侧边栏中显示开发者界面、**MCP 代理服务器**标签页（让 AI 助手可以操作 Studio），以及在游戏内执行命令的配套模组。普通玩家不需要它；除非你在用它做开发，否则保持关闭。这个选择会记在这台电脑上。

## Build 42 修复

这个标签页说明 Build 42 兼容层：Studio 写入它制作的每个合并补丁包中的一个文件，它会修补 Build 41 模组对 Build 42 已重命名或删除的内容的调用。只要有合并补丁包处于启用状态，第 1 到第 6 部分就总是生效。第 7 部分修补特定的模组，每个都有一个 **ON** / **OFF** 开关。开关会立即写入磁盘上的每个 Studio 补丁包；无需发布，游戏下次启动时会读取它。

## MCP 代理服务器

只在开启**开发者功能**时显示。选择你的 AI 客户端，点击**复制 MCP JSON**，然后粘贴到该客户端的配置文件中；下方会显示每个客户端的分步说明。不要双击运行 `pz-mcp-server.exe`：出现一个空白的黑色窗口是正常的，你的 AI 客户端会自己启动和停止它。

## 小提示

- 文件夹、语言、窗口和警告的选择会立即生效；除了兼容层开关（游戏下次启动时读取）之外，什么都不需要重启。

## 在 Linux 上

Linux 版（AppImage 或 .deb）会在常见文件夹中找到 Steam（`~/.local/share/Steam`、`~/.steam`、Flatpak 的文件夹），并在你的主文件夹中找到 Zomboid 文件夹。有些功能只能在 Windows 上使用：原地更新应用（在 Linux 上，**下载**会打开发布页面）、为 AI 助手移动和截取游戏窗口（停放、截图、点击、按键）、Windows 的内存不足日志、通过 Steam 客户端订阅，以及下载 SteamCMD（请从你的发行版安装）。保存的密钥和密码存放在私有文件 `~/.config/PZModStudio/secrets.json` 中，而不是凭据存储。对于 AI 客户端，使用 .deb 时控制台服务器是 `/usr/bin/pz-mcp-server`；AppImage 本身用 `--mcp` 提供 MCP。
