# 浏览模组

“浏览模组”是你寻找和获取新模组的地方：搜索 Steam 创意工坊和 Nexus Mods，翻看你已经有的模组，维护你自己的列表，以及安装你自己下载的模组。

## 你会看到什么

- 顶部有四个标签页：**Steam 创意工坊**、**Nexus Mods**、**我的模组**（带有你拥有的数量）和**我的列表**。切换离开时，每个标签页都会保留它的页码和筛选。
- 右侧是安装按钮：**安装 .zip / .7z**、**文件夹**和**从链接安装**。
- 每个模组是一张卡片，带有图片、游戏版本小标签（如 **B42**，页面没写时显示 **build ?**）、是否**已安装**，以及**更新等待中**或**上次游玩后新增**等小标签。把指针停在卡片上可以看到更多；点击打开它的详情视图；右键点击打开菜单（订阅、它的页面、复制它的链接或 ID、收藏、列表和配置方案）。

## Steam 创意工坊

- 在搜索框中输入并点击**搜索**。你也可以粘贴一个或多个创意工坊链接、ID 或合集链接：Studio 会正好显示这些项目，以及其中有多少是你还没有的。
- **排序**：**最热门**、**历史最高评分**、**最新发布**或**最近更新**。选择“最热门”时还可以选时间段（**今天**、**一周**、**三个月**、**一年**）。文字搜索总是按相关度排序。
- **游戏版本**：**Build 42**、**Build 41** 或**任意版本**。
- **模组**或**合集**：要列出什么。选择“模组”时还可以选类别；游戏版本筛选只对模组有效。
- **网页**会在你的浏览器中打开创意工坊。
- **翻译标题和简介**会用本应用的语言显示结果的标题和简介。在你点击它之前，不会向翻译服务发送任何内容。

如果 Steam 拒绝了搜索，会有一个框说明原因。如果 Steam 只是忙，点击**重试**。否则你可以粘贴一个个人的 Steam Web API 密钥并点击**检查并保存**；它只保存在这台电脑的 Windows 凭据管理器中，**移除它**会删除它。粘贴链接不需要密钥。

**通过 Steam 搜索**会通过 Steam 而不是创意工坊页面搜索：结果相同，但带有 Steam 的精确数字（订阅数、收藏数、大小），每页 50 个。搜索期间，Steam 会短暂显示你正在玩 Project Zomboid。游戏打开时，或搜索合集时，仍和平常一样使用页面。

## Nexus Mods

按模组名称中的词搜索，排序（**最近更新**、**下载最多**、**推荐最多**、**最新**）并选择类别。除非勾选**成人内容**，否则成人模组会被隐藏。

Nexus 的下载在 Nexus 网站上进行。在 Nexus 模组的详情视图中，**在 Nexus 上下载**会在你的浏览器中打开它的 Files 标签页。下载完成后，点击**安装 .zip / .7z** 并选择该文件；Studio 会把它标为 Nexus 模组。

## 我的模组

你安装的所有东西：创意工坊订阅、Nexus 模组和本地模组。可以按名称或 ID 筛选、选择**来源**、按**最近更新**或**名称**排序、选择类别，并用**上次游玩后新增**和**更新在 Steam 中等待**小标签只看这些。每张卡片会写明哪些配置方案包含该模组（当前的排在最前，显示为绿色；更多时显示 **+N**，悬停可看到名字），或显示**无配置方案**；**所有配置方案**筛选可以只显示某一个配置方案的模组，或不属于任何配置方案的模组。右键点击创意工坊模组可以**取消订阅**。在 Steam 发送你的项目的图片和详情期间（几秒钟），标签页会这样提示，而不是显示空卡片。

## 详情视图

点击卡片会打开一个大视图。顶部是标题、作者、**收藏**星标，以及作者提供了赞助链接时显示的**支持作者**。下面有两个标签页：**页面**（图片、视频和简介）和**评论**（人们在它的创意工坊页面上说的话，最新的在前，带有**加载更多**）。右侧是按钮、信息和前置模组。**返回**回到上一个，Esc 或 X 关闭它。

- **在模组列表中显示**：对于你已安装的模组，打开模组列表并选中该模组（用来启用或禁用它、移动它，或查看你的备注和诊断发现的问题）。

- **订阅** / **取消订阅**：通过 Steam 客户端完成，所以 Steam 必须在运行。Steam 下载文件；完成后该模组会出现在你的模组列表中。没有 Steam 时没有“订阅”按钮，**打开创意工坊页面**会显示为**打开页面去订阅**。
- **所需项目**：该模组在创意工坊上需要的东西，标为**已安装**或**缺少**。点击一个可以打开它。
- **Studio 的索引**：Studio 对该模组所了解的：它能运行的游戏版本、与它不搭的模组、已知问题以及 Studio 是否能修复，如果有适合你游戏版本的新版本也会列出。
- 标题栏中的星标会把它加入你的**收藏**。
- **翻译成 ...** 会用本应用的语言显示简介；**显示原文**会回到原文。只有你点击它时，文字才会被发送到翻译服务。
- 图片中的视频可以在视图中播放。如果作者不允许，**在 YouTube 上观看（浏览器）**会打开它。

对于合集，你会看到**订阅缺少的 N 个**（全部都有时显示**全部取消订阅**）、**用它创建配置方案**（一个包含该合集中你已安装模组的配置方案），以及你缺少的项目列表。

## 订阅模组需要的东西

当你订阅时，如果该模组需要你没有的其他创意工坊项目，会弹出一个窗口列出整条依赖链。缺少的默认勾选。选择**全部订阅 N 个**一次获取，**只要 X** 只订阅你要的那个，或**取消**。已经不在创意工坊上的项目会被标出。

## 我的列表

你自己的模组列表，保存在这台电脑上。**收藏**总是在那里。

- 在**新列表…**中输入名称并点击 **+** 来创建一个。
- 用详情视图中的星标添加模组，或右键点击任何模组并选择**收藏**、**加入列表…**或**加入配置方案…**。
- **订阅所有缺少的**会订阅列表中你没有的创意工坊项目。
- **创建配置方案**会创建一个配置方案，并启用列表中已安装的模组。
- 铅笔用来重命名列表，垃圾桶用来删除它。模组仍然保持安装。
- 右键点击卡片并选择**从……移出**，只把它从列表中移除。

## 安装下载的模组

- **安装 .zip / .7z**：选择一个压缩包。Studio 会找到其中的模组并放进 `Zomboid/mods`。
- **文件夹**：用于 `.rar` 或任何已经解压的内容。
- **从链接安装**：粘贴一个直接的 `.zip` 链接或 GitHub 页面。Studio 会显示它要下载什么，并先询问你。

如果该模组已经安装，替换之前会先问你；旧副本会被移到 `Zomboid/PZModStudio_Backups/mods`。一行绿色文字会确认安装完成。然后在模组列表中启用该模组。

## 小提示

- 订阅和取消订阅需要 Steam 客户端在运行。
- 取消订阅后，Steam 会晚些时候才删除文件，所以在 Steam 重启前，该模组可能还留在你的模组列表中。
- 所有网页都在你的浏览器中打开。
