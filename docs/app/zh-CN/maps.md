# 地图

“地图”界面把游戏世界和所有已安装的地图模组放在一张图上，让你看到地图替换了 Knox Country 的哪些部分，以及两个地图模组在哪里争夺同一块地。它还会列出不添加自己土地的地图模组，并提醒图块冲突。

## 你会看到什么

- 游戏世界的真实地图，每个地图模组的地图格用各自的颜色画在上面。
- 右侧是添加地图格的地图模组列表。
- 地图上方，每对共享地图格或图块编号的地图模组都会有一条警告。
- 下方是**其他地图模组**：出生点、地图列表和图块包。

世界被切成一个个地图格；一个地图格是 256 x 256 个图块。

## 在地图上移动

- 先点击地图，然后滚动鼠标**滚轮**来放大和缩小。缩放以指针下的位置为中心。在你点击之前，滚轮滚动的是页面（会有**点击地图后可用滚轮缩放**的提示），指针离开地图后也会恢复这样。
- **按住左键拖动**来移动地图。
- **双击**地图，或点击它右上角的按钮（**查看整张地图**），重新看到全图。
- 把指针停在一个地图格上，可以看到它的编号、它是否属于游戏世界，以及哪些地图覆盖了它（两个地图共享时显示**这里不止一张地图**）。

图片是用游戏和模组自带的地图图片拼成的。拼图期间会显示**正在拼合地图…**。没有附带图片的地图模组，它的地图格仍会显示为彩色方块。

## 颜色的含义

- **游戏世界**：基础地图，上面有一层淡淡的网格。
- **每个地图模组的颜色**：它的地图格。列表中名字旁边的小方块显示它的颜色。地图模组在游戏世界上的地图格会替换原来的内容。
- **红色**：两个地图模组共享的地图格。在那里，你的游戏中其中一个会替换另一个，除非一个是在另一个的基础上做的。

## 地图模组列表

每一行显示地图的名称、它来自哪个模组、有多少个地图格、其中多少个在游戏世界上（或**在游戏世界之外**）、它**基于**哪些地图，以及模组已禁用时显示**已禁用**。

- 取消勾选某行的复选框可在图上隐藏该地图。这只改变显示，不会改变你的模组列表。
- 点击某行的列表图标（**在模组列表中查看**）跳到模组列表中的该模组，并高亮显示。
- 勾选**只看我列表中已启用的地图模组**，只显示你已启用的地图。它也会隐藏只涉及已禁用模组的警告和其他地图模组。这个勾选会被记住。
- 顶部的刷新按钮会重新读取地图。你的模组列表变化时也会重新读取。

## 冲突

- **红色**警告表示两个地图模组共享地图格且都已启用：在你下一次游戏中，那里会有一个替换另一个。警告下方，每个模组都有一个在模组列表中查看它的按钮，以及一个**禁用**按钮（会先询问）。
- 只有在你启用了现在已禁用的模组时才会发生的冲突，会收成一行灰色（**如果启用现在已禁用的模组，可能有 N 处冲突：现在无需处理**）。展开可以看到每一处。
- 图块定义警告表示两个模组使用了同一个图块定义编号。如果两个都启用，它们的图块会互相覆盖，你会看到错误的墙、地板或家具。只保留一个启用。警告下方，每个模组都有一个在模组列表中查看它的按钮，当启用的不止一个时还有**禁用**。

## 其他地图模组

这些模组与地图有关，但不添加地图格：出生点、给另一张地图用的地图列表，或者构建地图用的图块。每个都标有**出生点 / 地图列表**或**图块**。它们需要所服务的地图或模组处于启用状态。点击一个可以在模组列表中查看它。

## 小提示

- 两张共享地图格的地图，如果其中一张在它的 `map.info` 中提到另一张（`lots=`），就不算冲突；列表会把这显示为**基于**。
- 地图图片只制作一次，保存在 `Zomboid/PZModStudio_Cache/maps/`，所以下次打开这个界面会更快。
- 这个界面上除了**禁用**之外，什么都不会改变你的游戏。
