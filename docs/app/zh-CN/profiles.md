# 配置方案

配置方案是一个有名字的模组列表：哪些模组属于它、其中哪些已启用，以及它们的加载顺序。你可以在这里创建配置方案、一键切换、分享和删除。在激活一个配置方案之前，其他大多数界面都会保持锁定。

## 你会看到什么

- 顶部显示你保存了多少个配置方案，以及**新建配置方案**按钮，它会打开一个窗口，分三步带你创建一个。
- 每个已保存的配置方案一张卡片，当前的排在最前。当前的那个有绿色边框、**当前**标签和**查看它的模组**按钮（打开模组列表）；其他的显示**未激活**，并有**激活（一键）**。
- 每张卡片显示它的描述、已启用的模组数量（**已启用模组**）、它顺序中的模组**总数**，以及游戏版本：手动设置时显示 **Build 41/42**，否则显示**游玩于 ...**，即最后一次从 Studio 游玩时的版本。

## 创建配置方案

点击**新建配置方案**：会打开一个分三步的窗口（**名称**、**哪些模组**、**检查**），每一步顶部都有说明。**下一步**和**返回**在步骤间切换；Esc 或 X 关闭窗口，什么都不会创建。

1. 输入**配置方案名称**（必填），愿意的话再输入**描述（可选）**。
2. 在**哪些模组**中，选择配置方案的起始内容：
   - **现在已启用的**：此刻已启用的模组。
   - **所有已安装的**：Studio 找到的所有模组。
   - **自己挑选**：一个带搜索框和**全部** / **无**按钮的列表；勾选你想要的模组。
   - **暂时不加**：一个空的配置方案。Studio 会请你确认，因为切换到它会禁用所有模组。有当前配置方案时，**在浏览模组中查找模组**按钮会带你过去先订阅。
3. 在**检查**中，你会看到名称以及开始时有多少模组处于启用状态。点击**创建并启用**。

新的配置方案会立即创建并激活，并沿用你列表现有的加载顺序。如果 Studio 还没有找到任何模组（应用设置中没有设置游戏或 Zomboid 文件夹），它会拒绝创建，免得配置方案误把你所有的模组都禁用。

## 切换配置方案

在卡片上点击**激活（一键）**。然后 Studio 会：

- 把该配置方案的模组写入游戏读取的列表（`Zomboid/mods/default.txt`）；
- 把它标为当前，并用它的顺序打开模组列表；
- 安装 PZ Mod Studio Link 模组并在每个配置方案中保持启用，让游戏的模组界面显示该配置方案。

如果配置方案中的某个模组需要在游戏的启动文件中加入 Java 代理（例如 Zombie Buddy），会先弹出一个窗口，显示哪些内容会从该文件中移除或加回。点击**启用 ...**继续。如果游戏正在运行，这一步会等到游戏关闭后再进行。之前会先保留一份启动文件的副本。

## 隔离此配置方案

**隔离此配置方案**会为该配置方案单独保存：

- 它的单人**存档**；
- **游戏选项**：画面、声音和按键；
- **模组的设置**：每个模组保存在 Zomboid 文件夹中的内容（它的选项、设置和数据）。

启用该配置方案时，游戏只使用它自己的这些内容；换成另一个配置方案时则使用那一个的（如果那一个没有隔离，就使用共享的）。隔离时你可以选择带走哪些共享的存档；其余的仍然共享。选项和模组设置一开始是你现在这些的**副本**，所以配置方案的起点和之前完全一样，其他配置方案也保留它们自己的。

**模组本身对每个配置方案都是同一份**：它们不会被复制或移动，也不需要重新安装。一个模组（或模组的一部分）在一个配置方案中启用、在另一个中禁用，照常工作。服务器的存档（`Saves/Multiplayer`）、游戏日志、服务器，以及本应用和 Link 的文件也不会被分开。

不属于设置的大数据在隔离配置方案时不会被复制：单个超过 20 MB 的文件或超过 50 MB 的文件夹（模组的缓存、录像或转储）会保持**共享**，从此对每个配置方案都是同一份，所以隔离永远不会塞满磁盘。游戏自己的选项和按键不论大小都会复制。哪些内容保持共享，会记录在 `Zomboid/PZModStudio_ProfileSavesShared.json` 中。

切换配置方案时，本应用通过重命名把所有东西放到位，不复制任何内容。它只在 Project Zomboid 关闭时这样做：包括游戏本身，以及这台电脑上的任何 Project Zomboid 服务器（“服务器”界面中 Studio 的服务器，或手动启动的服务器）。如果有正在运行的，本应用会说明是哪个，并请你先关闭它。属于其他配置方案的内容放在 `Zomboid/PZModStudio_ProfileSaves` 中等待。如果切换途中电脑关机，本应用会在下次打开时完成它。

本应用移动、复制或保留到备份中的每个存档和设置，都会写进 Studio 的日志（`Zomboid/PZModStudio_Logs/studio.log`，带有 `[Profiles]` 的行），注明从哪里到哪里，所以如果某个存档好像不见了，你可以查到它去了哪里。

**停止隔离**会把它的存档放回共享的存档中，并恢复共享的选项和模组设置；配置方案自己的那份保存在 `Zomboid/PZModStudio_Backups/ProfileSettings` 中，不会覆盖任何东西。删除配置方案也是这样处理，所以存档或设置永远不会丢失。

## 编辑、分享和删除

- 铅笔按钮（**重命名此配置方案**）打开**编辑模组配置方案**：修改名称、描述和**游戏版本**。版本可以保持为**按上次游玩**，或设为 **Build 41** / **Build 42**。设置了版本后，在其他版本上启动此配置方案之前 Studio 会先询问，即使它还没被游玩过。点击**保存更改**。
- 分享按钮把配置方案保存为一个 `.pzpack` 文件，你可以发给任何人。它只包含已启用的模组，按顺序排列，并附带它们的创意工坊 ID。打开它的人可以订阅自己缺少的模组。
- 垃圾桶按钮会在确认后删除配置方案。如果它的某些创意工坊项目没有被其他配置方案使用，确认窗口会列出它们（**只有此配置方案使用**），默认勾选，并有**全部勾选** / **全部不勾**。**删除并取消订阅**会删除配置方案并取消订阅勾选的项目（Steam 必须在运行）；**仅删除配置方案**会保留它们。其他配置方案使用的项目和本地模组永远不会被动到。如果配置方案使用了模组合并器生成的补丁包（`Z_PZModStudio_...`），还会再问一次是否也删除它们；**取消**会保留它们。

## 小提示

- 删除的配置方案并没有丢失：它的文件被移到了 `Zomboid/PZModStudio_Backups/profiles`。
- 删除当前配置方案后就没有当前配置方案了，游戏的模组界面也不再显示配置方案。
- 你在模组列表中做的更改（启用或禁用模组、调整顺序）会立即保存到当前配置方案中。
- 在游戏自己的模组界面中确定的更改也会回到当前配置方案中。
- 启用的模组会成为配置方案的模组之一。不属于任何配置方案的模组会在模组列表中提供**加入配置方案**。
- 存档永远不能跨大版本（41 和 42）使用，所以配置方案会记住它的游戏版本。
